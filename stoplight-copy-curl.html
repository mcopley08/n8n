🔍 Find The Working Endpoint

📋 Step-by-step instructions:
  1. Open developer.buildops.com in a new tab
  2. Open DevTools (F12 or Cmd+Option+I)
  3. Go to the Network tab
  4. In the filter box, type: stoplight.io
  5. Navigate through the documentation (click on different pages)
  6. Look for requests to stoplight.io/api/v1/
  7. Find a request that returns documentation content (status 200, looks like JSON)
  8. Right-click on that request → Copy → Copy as cURL
  9. Paste the cURL command below
